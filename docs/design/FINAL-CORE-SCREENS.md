# 제비 핵심 4화면 디자인 전달본

2026-10-01. 이번 범위는 화면 시안과 현재 구현의 시각·문구·행동 정리다. 독립 참석/안부 모델, DB 마이그레이션, 복구, 운영 계측은 이 디자인 작업에서 확장하지 않는다.

## 화면별 결정

| 화면 | 정보 순서 | 주 행동 | 구현 마감 |
|---|---|---|---|
| 온보딩 | 컨셉 → 실용성 → 첫 기록 | 다음 / 첫 소식 입력 | 3장·기존 제비와 초가집. 예시 격리, 실패 유지, 부고 중립 완료 |
| 홈 | 가까운 일정 → 미정 날짜 → 우리 집 → 기록 요약 | 일정 확인 / 소식 기록 | 받은/전한 마음을 일정과 구분. 알림 카드도 기록 확인으로 열며 자동 완료 없음. 답례를 기다린다는 압박 문구 제거 |
| 입력 | 목적 → 상대/행사 → 날짜·장소 → 실제 금품 정보 | 일정 저장 / 실제 마음 저장 | 목적 카드, 390px 이하 세로 카드, 입력 이름·44px 수정 버튼·인라인 오류 |
| 상세 | 인연 → 기록 추가/수정 → 기억/금품 → 타임라인 | 기록 열기 / 기록 추가 | ‘인연의 기억 / 돈·선물 기록’ 명확한 라벨. 일정은 소식으로 표시하고 금품 목록/답한 기록 버튼에서 제외. 목록을 키보드 버튼으로 제공 |

화면 배경은 #FCFBF9, 종이색 #F7F0E2, 주요 행동은 #9A6410. 앱의 기존 토큰을 사용하고 삽화는 public/img의 기존 파일을 그대로 재사용한다. 복은 관계의 온기라는 서사이며 금액·구매 보상이 아니다.
