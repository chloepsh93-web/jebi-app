# 복구 경로 후속 검수 — 2026-10-01

## 개발자 전달문

PR #1의 핵심 화면 개선을 Vercel 프리뷰에 연결하고, `docs/design/DEVELOPER-HANDOFF.md` 순서로 검수해주세요. 기존 제비·초가집 이미지는 유지합니다. 테스트 통과는 실기기 화면과 실제 Supabase 복구 검수를 대신하지 않습니다. 운영 배포 전에 프리뷰 주소와 검수 결과를 남겨주세요.

이번 후속 수정은 CSV 내보내기/가져오기에서 현금·선물 분류가 사라지던 문제를 해결합니다. 현재 `cash/goods`와 기존 `money/gift/help` 값을 각각 보존합니다. 월만 아는 날짜, 참석 미정, 0원과 금액 미입력도 왕복 보존합니다. 음수·소수·잘못된 날짜를 임의로 양수나 다른 날짜로 고쳐 저장하지 않고 형식 오류로 처리합니다. 방식·참석·메모 등이 다른 기록을 같은 기록으로 건너뛰지 않도록 중복 기준을 보완했습니다.

## 검증 범위

총 테스트 16개: 기존 접근성/화면 8개 + CSV 복구 8개. 복구 테스트는 저장소를 모의하여 네트워크와 실제 사용자 기록을 변경하지 않습니다. 실제 서버 컬럼의 존재 여부와 세션 복구는 이 테스트로 확인되지 않습니다.

## 반드시 구분할 한계

CSV는 기록 이동용 포맷이며 모든 데이터의 완전한 백업이 아닙니다. 현재 포맷은 원본 ID, 박씨 연결, 태그·공동선물 상세, 실제 교환 시각 등을 전부 보존하지 않고 기록 시각도 분 단위입니다. 내용이 같은 별개 기록은 중복 후보가 될 수 있습니다. 같은 이름의 인연이 여러 명이면 자동 귀속하지 않고 확인 필요로 건너뜁니다. 따라서 서버 백업·이메일 계정 복구를 CSV로 대체하면 안 됩니다.

마음 테이블의 `asset_kind`, `attendance`, `date_precision` 지원을 실제 프리뷰 프로젝트에서 확인해야 합니다. 해당 컬럼이 없는 서버에서 저장 계층이 폴백하면 관련 정보가 보존되지 않을 수 있습니다. DB 변경은 이 PR에서 자동 적용하지 않았습니다.
